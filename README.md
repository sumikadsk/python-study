# Excel自动化数据处理工具

# 项目简介
基于 Python 开发的轻量化办公自动化工具，实现多 Excel 文件批量读取、数据清洗、去重、自动生成汇总报表，替代人工重复操作，大幅提升办公数据处理效率。

##  技术栈
- Python 3.x
- openpyxl 库（Excel 文件读写）
- 文件批量遍历与异常处理
- Git 版本控制

##  核心功能
1.  批量读取指定目录下所有 Excel 文件
2.  自动过滤空白无效行、剔除重复数据
3.  整合多文件数据，自动生成标准化汇总报表
4.  加入异常捕获机制，提升程序稳定性

##  使用方法
1.  安装依赖：`pip install openpyxl`
2.  将待处理的 Excel 文件放入项目目录
3.  运行脚本：`python 自动化处理excel.py`
4.  自动生成汇总结果文件：`汇总报表.xlsx`

##  项目成果
- 替代人工手动复制、去重、整理表格等重复操作，处理效率提升约 80%
- 代码结构规范、注释完善，具备小型办公自动化工程落地能力
